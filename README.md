# ProyectoFinal-Samsung
Al inicio del proyecto, mis compañeros y yo nos dividimos las tareas principales según nuestras fortalezas: uno se encargó del análisis de sentimiento, otro del análisis de voz y otro del análisis de imágenes. La idea original del bot era crear un asistente dirigido a personas jubiladas para brindar información sobre fechas de cobro y trámites, ofreciendo un soporte sencillo y accesible. Sin embargo, durante el desarrollo se decidió enfocar el proyecto en un público más amplio: clientes que enfrentan problemas con la tecnología, lo que dio origen a la creación de TecnoMant, cuyo nombre surge de la combinación de “Tecnología” y “Mantenimiento”, reflejando la misión del bot de brindar asistencia tecnológica y soluciones a problemas técnicos de manera confiable y práctica.    

En este contexto, mis compañeros y yo desarrollamos un bot de Telegram integral que combina análisis de texto, voz e imágenes, diseñado para mejorar la interacción y el soporte a los usuarios mediante inteligencia artificial.

Para el análisis de texto, el bot interpreta el sentimiento de los mensajes escritos (positivo, negativo o neutro) utilizando Python, la librería Telebot para la comunicación con Telegram, logging para registrar actividad y el modelo preentrenado “pysentimiento/robertuito-sentiment-analysis”. Se implementaron funciones como _normalizar_label(), para estandarizar las etiquetas del modelo, y generar_respuesta(), para producir respuestas empáticas basadas en palabras clave y en el sentimiento final. Además, se configuraron manejadores para los comandos /start y /help, y se mantuvo la ejecución continua con bot.infinity_polling().

El análisis de voz permite al bot responder consultas sobre los servicios y datos de la empresa TecnoMant a partir de audios. Se integró Telebot con la API de Groq, utilizando el modelo LLaMA 3.3 para generar respuestas coherentes y el modelo Whisper-large-v3 para transcribir voz a texto con alta precisión. Toda la información proviene del archivo dataset.json, que actúa como base de conocimiento y contiene historia, servicios y contactos de la empresa. Se implementaron funciones como load_company_data() para cargar el JSON, get_groq_response() para comunicarse con la IA y trascribe_voice_with_groq() para procesar los audios. También se incorporó manejo de excepciones para reiniciar el bot ante fallos y se protegieron las claves mediante variables de entorno.

Para el análisis de imágenes, el bot recibe fotos de los usuarios, las convierte a formato base64 y las envía al modelo meta-llama/llama-4-scout-17b-16e-instruct a través de la API de Groq. El modelo identifica fallas de hardware o software y genera diagnósticos que incluyen posibles causas, soluciones básicas para usuarios, soluciones avanzadas para técnicos, precauciones y recomendaciones preventivas. El flujo del código incluye validaciones de entrada, manejo de errores y comandos de ayuda para guiar la interacción.

En conjunto, este bot combina procesamiento de lenguaje natural, análisis de sentimientos, transcripción automática de voz y análisis visual de imágenes. La arquitectura del código se organizó en funciones modulares, con manejo seguro de errores y protección de credenciales mediante variables de entorno. El resultado es un asistente inteligente integral, capaz de interpretar distintos tipos de contenido, responder de manera empática y ofrecer soporte técnico confiable a los usuarios.
